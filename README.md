# 🎵 Daniel Caesar Website

A simple, responsive website dedicated to Daniel Caesar, the Canadian singer-songwriter known for his soulful R&B and neo-soul music. This project showcases his biography, albums, and awards using HTML and CSS.

Preview: https://jamesticao-dev.github.io/informationalwebsite/

---

### 🌟 Features
- Clean and responsive header navigation
- Biography section highlighting Daniel Caesar’s musical journey
- Dedicated pages for Albums and Awards
- Footer with About and quick navigation links
- Styled using CSS for a modern look

---

### 🛠️ Technologies Used
- HTML5
- CSS3
- Responsive design techniques
